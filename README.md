# Бункер & Мафия — сайт с онлайн-играми

Сайт на чистом HTML/CSS/JS (без сборки), backend — **Supabase** (бесплатно).
Хостинг — **GitHub Pages**.

## Что внутри
- Регистрация/вход по нику и паролю
- Личная статистика (сыграно/побед по каждой игре)
- 🏕 **Бункер** — до 15 игроков, карточки, раскрытие по кругу, голосования, до финального состава бункера
- 🔪 **Мафия** — классика: мафия/доктор/комиссар/мирные, ночь → день → голосование, до победы одной из сторон
- ⚙ Админ-панель: список игроков и статистики, назначение админов, удаление комнат

## Шаг 1. Создать проект Supabase
1. Зайти на https://supabase.com → **New project** (бесплатный план достаточно).
2. Дождаться создания проекта (1-2 минуты).
3. Слева зайти в **Authentication → Providers → Email** и **выключить "Confirm email"**
   (иначе после регистрации нельзя будет сразу войти — письма на фейковый e-mail никто не получит).
4. Слева зайти в **SQL Editor → New query**, вставить содержимое файла `sql/schema.sql` из этого проекта и нажать **Run**.

## Шаг 2. Подключить сайт к Supabase
1. В Supabase: **Project Settings → API**.
2. Скопировать **Project URL** и **anon public key**.
3. Открыть файл `js/config.js` и вставить их вместо заглушек:
   ```js
   const SUPABASE_URL = "https://xxxxxxx.supabase.co";
   const SUPABASE_ANON_KEY = "eyJhbGciOi...";
   ```

## Шаг 3. Выложить на GitHub Pages
1. Создать новый репозиторий на GitHub (например `bunker-mafia`).
2. Залить туда все файлы этой папки (`index.html`, `lobby.html`, папки `css/`, `js/` и т.д.) — через веб-интерфейс (Add file → Upload files) или через git:
   ```
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/bunker-mafia.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source → Deploy from a branch → main / (root)** → Save.
4. Через минуту сайт будет доступен по адресу вида
   `https://ВАШ_ЛОГИН.github.io/bunker-mafia/`

## Шаг 4. Стать админом
1. Зарегистрируйтесь на сайте под своим ником.
2. В Supabase → **SQL Editor**, выполните:
   ```sql
   update profiles set is_admin = true where nickname = 'ВАШ_НИК';
   ```
3. Зайдите на сайт заново — в лобби появится кнопка «⚙ Админка».

## Как играть
- **Бункер**: хост создаёт комнату, скидывает код друзьям (кнопка "Создать комнату" → лобби). Минимум 4 игрока. Хост жмёт "Начать игру" — каждому раздаются карточки. По очереди игроки раскрывают по одной карте за раунд, затем голосование за изгнание — так до нужного числа выживших.
- **Мафия**: то же самое с созданием/подключением по коду. Минимум 4 игрока. Роли раздаются автоматически (примерно 1 мафия на 3 игроков, комиссар с 5 игроков, доктор с 6). Ночью мафия/доктор/комиссар делают ход в своём интерфейсе, утром — общее обсуждение вслух и голосование.

## Важные технические ограничения (честно)
- Это MVP без отдельного сервера — вся логика игры выполняется в браузерах игроков, синхронизация идёт через базу данных Supabase в реальном времени. Ведущему (хосту) комнаты желательно не закрывать вкладку во время игры — именно его браузер досчитывает переходы фаз (ночь→день, подсчёт голосов).
- Роли в Мафии скрываются только на уровне интерфейса, а не сервера (там нет отдельного бэкенда с проверкой прав) — теоретически продвинутый пользователь через консоль браузера может подсмотреть чужую роль. Для игры с друзьями на доверии это не проблема.
- Права доступа к базе (RLS) в `schema.sql` намеренно сделаны довольно открытыми, чтобы игра работала без сервера. Не используйте эту базу для чего-то важного/приватного.
- Бесплатный тариф Supabase спит после долгого простоя и "просыпается" за пару секунд при первом запросе — это нормально.
